Not jailbroken? Fix "cannot connect" anyway

Install the same certificates as a profile — no Cydia needed. Open this page in Safari on the device.

Tap the button below in SafariIt opens the install page. Tap Install all there.
Tap InstalliOS will say the profile is "Unsigned" — that's normal for profiles that aren't from a company.
iOS 10.3 only: turn on trustSettings → General → About → Certificate Trust Settings, then switch on each certificate.
Install the certificates See the certificate list

To remove it later: Settings → General → Profiles (or Profiles & Device Management) → Ben's Cert Fix → Remove.

How to add the repo

On your jailbroken device.

Open CydiaThe jailbreak app store on your device.
Go to Sources → Edit → AddTop-right buttons in the Sources tab.
Enter the URLbentechie123.github.io/benscoolrepos/
Install what you wantOpen the source and tap a package to install it.

On the device itself you can also just tap the Add to Cydia button at the top — it opens Cydia and fills the URL in for you.
